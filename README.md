# Sugarcane Production Analysis

## Project Description

This project is based on the analysis of sugarcane production data from different countries around the world. The analysis was performed using Python to understand production patterns, yield performance, cultivated area, and continent-wise contribution.

The dataset was cleaned and explored using Pandas. Different charts and graphs were created with Matplotlib and Seaborn to study the data and find useful insights.

---

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Analysis Performed

- Production distribution by continent
- Number of producing countries by continent
- Continent-wise production comparison
- Acreage distribution analysis
- Yield vs Production analysis
- Acreage vs Production analysis
- Top 10 countries by yield
- Top 10 countries by acreage
- Top 10 sugarcane producing countries
- Distribution analysis
- Box plot analysis

---

## Main Observations

- Brazil has the highest sugarcane production.
- India is the second-largest producer.
- South America contributes the largest share of total production.
- Africa has the highest number of sugarcane-producing countries.
- Countries with larger cultivated areas generally produce more sugarcane.
- Production is concentrated in a few major countries.

---

## Conclusion

The project helped in understanding sugarcane production patterns across different countries and continents. It also provided practical experience in data cleaning, visualization, and exploratory data analysis using Python.
